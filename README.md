# 🏢 LLM 模型池 (LLM Pool)

> **把大模型当牛马管！让你的模型背上 KPI：能者上、庸者下，慢的优化、崩的开除！**  
> 组间竞争、梯队化管理、末位淘汰、延迟对冲赛马、全维度 KPI 监控大盘，帮你的 Bot 调教出最卷、最稳的模型战队。

## 工作原理

插件不修改 AstrBot 内核，只在系统内注册并维护一个稳如老狗的虚拟员工（默认 `llm-pool`）。AstrBot 以为自己在调用单个模型，背后其实是一整个被 KPI 卷飞的模型战队：

- **自动化人力调度**：任务派发、轮询排班、加权倾斜、超时催办、停职反省、背锅重试，全部交给插件自动搞定。
- **正规入职成员**：池成员必须是 AstrBot 中已配置好的真实模型 Provider。
- **廉洁透明**：插件自身不持有任何上游 API Key，杜绝私藏中转。

### 专用节点池（编制外独立项目组）

除主模型池外，还可以开多个**专用节点池**（如轻量判定池、意图识别池、语音识别池等），每个池独立拥有：

- 专属 Provider ID、独立分组名、专用虚拟模型名
- 严格组隔离（专款专用，不跨组回退，绝不污染主力编制）
- 独立的调度策略、超时时限与最大重试次数

专用节点池独立于主链梯队，专攻细分业务，不参与主力向下击穿。

## 核心管理机制

### 调度策略（排班考核谁先上）

| 调度策略 | 说明 |
|---|---|
| `usage-based-routing-v2` | 并发负载与权重综合调度（默认推荐，兼顾负荷与能效） |
| `least_busy` | 纯最闲优先（谁手头活最少谁上） |
| `latency_based` | 纯延迟优先（谁手速快谁上，最快响应） |
| `weighted_random` | 按权重随机派活 |
| `round_robin` | 顺次轮流值日 |
| `ordered_failover` | 严格按资历花名册顺序派活 |

### 绩效考核制度（什么时候开罚单与优化）

- **报错或超时** → 立即开出罚单进入冷却期，期间停职不再派活
- **限流 / 欠费 (429)** → 触发限流冷冻惩罚，冷静期过后方可复职
- **常规报错** → 触发常规熔断冷却，防止雪崩蔓延
- **上游 502 / 彻底阵亡** → 停职深度休眠至次日凌晨 02:00 自动复职复盘
- **全员躺平熔断？** → 启动全员紧急特赦重试一次，绝不让整个池永久卡死
- **分类量化考核**：连续失败容忍次数可按限流、超时、400 业务报错与激进节点独立配置

### 组内加权重试 (Weighted Failover)

开启后，同组节点失败重试时不再死板按列表顺序，而是**按权重随机重新摇号**，把重试压力均匀分摊到同组的不同区域或多个 API Key 上，杜绝单点被抓着薅到死。

### 狼性高阶调度

- 🏇 **延迟对冲赛马 (Hedging)**：主力员工超时磨洋工？到达阈值立刻拉起同组备选并行竞速抢答，谁交卷快采纳谁，取消慢节点的后续等待。
- 📈 **拥堵提权 (Congestion Promotion)**：早晚高峰主力组集体卡顿或大面积熔断时，系统自动把后备保底组顺序提拔为主力接管大局。
- ⚡ **激进抢跑模式**：专为白嫖 / 免费 / Flash 节点打造，快速试探抢答，超时敏锐熔断、恢复后宽容解封。

## 快速上手

1. 安装并启用插件。
2. 打开插件的**可视化页面**，首次进入会自动弹出使用指引。
3. 在「🎛️ 模型池配置管理」点击 **📥 导入 Provider** 一键导入 AstrBot 已配置的对话模型，或手动选择 / **➕ 手动输入**添加成员。
4. （可选）为成员设置模型组（如 `tier1`、`tier2`、`tier3`），拖拽 ⠿ 手柄调整优先级。
5. （可选）在「🔄 跨组回退链」配置降级顺序（如 `tier1 → tier2 → tier3`）。
6. 点击 **💾 保存全部配置**。
7. 进入 AstrBot 管理面板的**提供商设置**，在**对话模型**或**回退对话模型**中选择 `llm-pool`。

> 💡 `llm-pool` 是虚拟路由入口，不需要填写 API Key、API Base URL，也不需要手动获取模型列表。

### 配置专用节点池

1. 在「🔑 专用节点池」中添加一个池，设置 Provider ID、分组名、模型名。
2. 在模型池成员中，为该分组添加真实 Provider。
3. 在 AstrBot 中即可选择该专用池的 Provider ID 作为特定场景的模型入口。

### 配置导入导出

- **导出**：点击配置页顶部 **📤 导出**，下载 `llm_pool_config.json` 完整配置快照
- **导入**：点击 **📥 导入**，选择之前导出的 JSON 文件，确认后覆盖当前配置
- **清空 / 重置**：在「⚙️ 插件管理」标签页可清空成员或一键重置为默认配置
